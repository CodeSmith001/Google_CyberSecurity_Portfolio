# Portfolio Activity: The Incident Handler's Journal

## 📝 Objective
The objective of this project was to establish and maintain a professional Incident Handler's Journal. This journal tracks the entire lifecycle of various cybersecurity incidents, documenting the tools used, the threat actors involved, the technical commands executed, and the ultimate mitigation strategies deployed.

## 🛠️ Skills Demonstrated
- **Incident Response Lifecycle Tracking**
- **Technical Documentation & Reporting**
- **Threat Intelligence Analysis:** VirusTotal, APT profiling
- **Intrusion Detection Systems (IDS):** Suricata rule syntax, `jq` JSON parsing
- **Network Traffic Analysis:** `tcpdump`, `.pcap` analysis, hexadecimal inspection
- **SIEM Operations:** Wazuh log querying and threat hunting

## 🏢 Project Overview
In a Security Operations Center (SOC), meticulous documentation is as critical as technical proficiency. This journal serves as a running log of simulated and practical investigations conducted throughout the Google Cybersecurity Pro
